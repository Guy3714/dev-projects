

# 🧪 Flask Starter Project: Hello World App

## 🎯 Objective

Build your first backend server using Flask that returns a simple message.

---

## 📌 Problem Statement

Create a Flask application that:

1. Runs a local web server
2. Has a single route `/`
3. When opened in a browser, displays:

```
Hello, World! 🚀
```

---

## 🛠 Requirements

* Use Python
* Use Flask
* File name should be: `app.py`

---

## 📋 Steps to Follow

1. Install Flask (if not installed):

   ```bash
   pip install flask
   ```

2. Create a file named `app.py`

3. Import Flask

4. Create a Flask app instance

5. Create a route `/`

6. Return a simple string message

7. Run the app

---

## ▶️ Expected Output

When you open:

```
http://127.0.0.1:5000/
```

You should see:

```
Hello, World! 🚀
```
