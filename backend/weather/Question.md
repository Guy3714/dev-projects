# 🌤 Flask Mini Project — Weather Report Page

## 🎯 Objective

Build a Flask app that displays a dynamic weather report using Jinja variables.

---

# 📋 Task

Create a Flask application with a route:

```
/weather
````

Pass the following data from Flask to HTML:

```
city = "Kolkata"
temperature = 34
condition = "Sunny"
humidity = 70
```

---

# 🌐 HTML Page (`weather.html`)

Display:

# 🌦 Weather Report

Show:

* City name
* Temperature
* Weather condition
* Humidity

Example:

```
📍 City: Kolkata
🌡 Temperature: 34°C
☀ Condition: Sunny
💧 Humidity: 70%
```
