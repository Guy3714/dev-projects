# 🛒 Flask Mini Project — FreshMart Grocery Store Website

## 🎯 Objective

Learn how to use **render_template()** to display HTML pages instead of plain text.

---

# 📋 Task

Build a Flask website for a grocery store called **FreshMart**.

---

## 🏠 Home Page

Route:

```python
/
```

Render:

```html
home.html
```

Page content:

```text
Welcome to FreshMart Grocery Store
Fresh and Healthy Products Everyday!
```

Add links to:

- Products Page
- Contact Page

---

## 🥕 Products Page

Route:

```python
/products
```

Render:

```html
products.html
```

Display the following products:

- Apples
- Bananas
- Milk
- Bread
- Eggs

Use an HTML unordered list (`<ul>`).

---

## 📞 Contact Page

Route:

```python
/contact
```

Render:

```html
contact.html
```

Display:

```text
FreshMart Grocery Store
Phone: 9876543210
Email: freshmart@email.com
```
