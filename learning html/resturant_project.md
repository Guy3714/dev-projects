# 🍽️ Minor Project: Restaurant Website (Menu + Table Booking)

## 🎯 Objective
Create a single HTML page for a restaurant that includes a menu, categories, and a table booking form.

---

## 🧱 Part 1: Header Section
- Set the page title to **Foodie's Restaurant**
- Add a main heading: **Welcome to Foodie's Restaurant**
- Add a short paragraph describing the restaurant

---

## 📊 Part 2: Menu Table

Create a table to display the restaurant menu.

### Table Columns:
- Category
- Item Name
- Price

### Requirements:
- Use **rowspan** for Category (same category should span multiple rows)
- Use **colspan** to create a heading row: **Our Menu**

### Categories to include:
- Starters
- Main Course
- Desserts

---

## 📚 Part 3: Menu Categories (Nested List)

Create a section titled: **Our Specialties**

Use nested lists to display:

- Starters
  - Soup
  - Spring Rolls
- Main Course
  - Paneer Butter Masala
  - Chicken Curry
- Desserts
  - Ice Cream
  - Gulab Jamun

---

## 📝 Part 4: Table Booking Form

Create a form with the following fields:

- Name (text input)
- Phone Number
- Email (email input)
- Number of Guests (dropdown)
- Date (date input)
- Time (time input)

### Seating Preference (Radio Buttons):
- Indoor
- Outdoor

### Add-ons (Checkboxes):
- Birthday Decoration
- Candle Light Dinner

- Special Request (textarea)
- Submit button

---

## ⚡ Additional Requirements
- Use proper `<label>` for all inputs
- Add placeholder text where appropriate
- Make one dropdown option **selected by default**
