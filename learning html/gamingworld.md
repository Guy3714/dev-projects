
## 🎮 HTML Assignment: *“My Gaming World”*

### 🎯 Objective

Create a **gaming profile webpage** for a person who loves video games (Jatin 😎), using only basic HTML text tags.

---

## 📋 Mandatory Tags (ALL must be used)

You **must** use each of these at least once:

`<h1>` `<p>` `<b>` `<i>` `<u>` `<a>`


✅ Only HTML

---

## 📝 Page Content Instructions

### 1️⃣ Game Page Title

* Use an `<h1>` tag
* Text should be:

> **Jatin’s Gaming World**

---

### 2️⃣ Gamer Introduction

* Use a `<p>` tag
* Write **3–4 lines** introducing Jatin as a gamer
* Inside this paragraph:

  * Use `<b>` for **favorite game**
  * Use `<i>` for **gaming style or genre** (e.g., competitive, open-world, FPS, RPG)

💡 Example idea:

> Jatin loves playing **Minecraft** and enjoys *open-world exploration* games.

---

### 3️⃣ Favorite Games Section

* Use another `<p>` tag
* Mention **2–3 favorite games**
* Underline the **most favorite game** using `<u>`

Example idea:

> His all-time favorite game is <u>GTA V</u> because of its freedom and storyline.

---

### 4️⃣ Gaming Motivation

* Use a `<p>` tag
* Make one **strong statement** about gaming using:

  * `<b>` and `<i>` in the same sentence

Example:

> Gaming helps improve <b><i>focus and creativity</i></b>.

---

### 5️⃣ External Gaming Link

* Add a clickable link using `<a>`
* Link to:

  * YouTube gaming channel
  * Steam
  * Epic Games
  * Roblox
* The link text must describe the link

Example:

> Visit my favorite gaming platform

---

## 📁 File Rules

* File name: `index.html`
* Must include:

  * `<html>`
  * `<head>`
  * `<title>` → “Gaming Profile”
  * `<body>`
