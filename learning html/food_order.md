# 🍕 HTML Form Assignment – Food Order Form

## 📝 Objective
Create a **Food Order Form** using HTML.

---

## 📋 Instructions

Design a form with the following fields:

### 1. Customer Details
- Full Name (text input)
- Phone Number (number input)

---

### 2. Pizza Size (Radio Buttons – only one selectable)
- Small
- Medium
- Large

---

### 3. Toppings (Checkbox – multiple selectable)
- Cheese
- Pepperoni
- Mushrooms
- Olives

---

### 4. Delivery Address
- Multiline input (textarea)

---

### 5. Payment Method (Dropdown)
- Cash on Delivery
- Credit Card
- UPI

---

### 6. Extra Instructions
- Multiline input (textarea)

---

### 7. Submit Button
- Label: "Place Order"

---

## 🎯 Requirements

- Use proper `<form>` structure
- Group related fields using headings
- Use labels for all inputs
- Ensure radio buttons share the same `name`
- Checkboxes should allow multiple selections

---

## ⭐ Bonus Challenge (Optional)

- Add a **required** attribute to important fields
- Add a **reset button**
- Add placeholder text where suitable

---

## 💡 Expected Outcome

A clean and structured **Food Order Form UI** with all input types working correctly.
